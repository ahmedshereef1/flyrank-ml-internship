HOW TO USE THIS FILE
---

1. Open your Content Decline Scout Claude Project.
2. Fill in the fields above with real values from your last session.
3. Paste the assignment card text if you have it (copy from the course site).
4. Send as your first message.
5. The agent returns a brief + next steps. Read it, then start working.

"SESSION STATE NOTE FROM LAST TIME" field above.
