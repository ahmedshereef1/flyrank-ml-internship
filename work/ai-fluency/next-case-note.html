Part 1 — The method

How to add the next case study

Every case follows the same three-beat shape. Write it in that order first, then drop it into the portfolio site. This note is the complete recipe — no rebuild needed.

The three-beat shape (Week 2 template)

Problem One sentence: what was broken or unknown before you touched it. No jargon; a non-technical person should grasp it.
What I did Two to four sentences: the approach, the tools, the key decision. What made this your solution and not the obvious one.
What came of it One to two sentences: the measured outcome. A number always beats a description — "84% Precision@50 vs 39% base rate" beats "significantly better than random".
  1. 1 Draft the three beats in your Claude Project. Paste your notes, notebook outputs, or a PR description — say "turn this into a three-beat case study". Your Claude Project already knows your voice, stack, and the FlyRank context, so it needs minimal prompting.
  2. 2 Open work/ai-fluency/site/index.html in the repo. Find the id="building" section. The current case study lives in the .build-card block as a label + result line.
  3. 3 Add a new card above the existing one. Copy the .build-card markup, update the .label to the project name and the p to your three-beat summary. Keep it to three to five lines — the site's strength is its density.
  4. 4 Update the hero subtitle to reflect the new work. The .hero-sub paragraph is one sentence — revise it so a recruiter landing cold knows what you're building now, not what you built last.
  5. 5 Push to GitHub — Netlify auto-deploys from work/ai-fluency/site/ on every push to main. The live URL stays the same: ahmedsherif565.netlify.app.

Part 3 — The reminder

Concrete reminder set

A named next piece without a trigger is still a vague intention. The reminder below is set:

📅

Recurring calendar nudge

First Monday of each month — "Portfolio update: is there a new case to add?"
Set in Google Calendar as a recurring event, no invitees, 15-minute block. The sole agenda: open this note, check if any work from the past month has a three-beat story, and draft it if so. If nothing is ready, the block takes five minutes to close. The friction is near zero; the habit compounds.

🔔

Project-specific trigger

When the time-series extension produces a Precision@50 result — add the case immediately.
Notebook outputs decay in clarity the longer you wait. The rule: if a notebook run produces a number worth keeping, draft the three beats the same day. The Claude Project is open; it costs less than ten minutes while the context is still live in your head.
