What I'm building

The core question: which content pages should a team review first? Not every page, not the obvious ones — the ones where the signal pattern says decline is underway before traffic has visibly dropped.

The model classifies each page as declining or stable using 29 features (search, engagement, freshness, position signals) and ranks the output into a prioritized queue. The metric that matters is Precision@50 — of the top 50 items flagged, how many are actually declining.

Latest result

Random Forest: 84% Precision@50 on held-out clients (39% base rate). Rule-based baseline: 28%. The gap closes the case for using a model over a spreadsheet formula.
